# Git Workflow Automation Rule

Al finalizar cada tarea, corrección o funcionalidad:
1. `git add .`
2. `git commit -m "<tipo>(<alcance>): <descripción de lo realizado>"`
   - Seguir conventional commits (ej: `feat(...)`, `fix(...)`, `refactor(...)`).
   - Sin atribución de IA ("Co-Authored-By" prohibido).
3. `git push` ESO LO HACES VOS .
