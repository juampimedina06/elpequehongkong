# Agent Instructions & Workflow Rules

## Git Workflow Obligatorio
Al completar cada tarea, corrección o cambio de código:
1. `git add .`
2. `git commit -m "<descripción de lo realizado>"`
   - Usar conventional commits (ej: `feat(...)`, `fix(...)`, `refactor(...)`).
   - Sin atribución de IA ni co-authored-by.
3. `git push` NO HACER ESTO (lo realizas vos).
